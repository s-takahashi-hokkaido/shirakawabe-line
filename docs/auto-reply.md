# 自動応答・あいさつメッセージの設計

**すべて無料（通数を消費しない）。ここに情報を厚く置くほどコストが下がる。**

## 1. あいさつメッセージ

友だち追加直後に自動送信される。**唯一の「確実に読まれる」メッセージ。**

設計方針:
- 自己紹介を長々と書かない。**「このアカウントで何ができるか」を伝える**
- リッチメニューへの誘導を入れる
- 友だち追加してくれたことへの感謝を入れる

### 叩き台

```
友だち追加ありがとうございます。
白川部けいた（しらかわべ けいた）です。

このアカウントでは、
・活動のご報告
・街頭演説や集会の予定
・政策のご案内
をお届けします。

下のメニューから、気になるものを選んでみてください。

ご意見・ご質問は、このままメッセージを送っていただければ
できる限りお返事します。

TBD: 連絡先表示（選挙運動期間中は表示義務あり）
```

> TBD:本人のトーン（一人称、文体）確定後に書き直す。

## 2. キーワード自動応答

リッチメニューの「テキスト」アクションと組み合わせて使う。

| キーワード | 返す内容 | 発火経路 |
|---|---|---|
| 政策 | 政策の一覧（カードタイプメッセージ） | メニュー / 直接入力 |
| よくある質問 | FAQ一覧 | メニュー / 直接入力 |
| お問い合わせ | 受付メッセージ + 1:1チャットへの誘導 | メニュー / 直接入力 |
| 予定 / 演説 | 直近の活動予定 | メニュー / 直接入力 |
| プロフィール / 経歴 | 経歴の要約 + サイトへのリンク | 直接入力 |

### 標準機能の制約

管理画面の応答メッセージは**完全一致・部分一致ベース**で、表記揺れに弱い。

- 「政策」は拾えるが「せいさく」「公約」「マニフェスト」は別途登録が必要
- **想定される言い換えを洗い出して登録する**こと
- 揺れへの対応が限界に達したら Phase 1 でコード化する

## 4. 応答設定の注意

管理画面の「応答設定」で以下を個別にON/OFFできる。

- チャット（手動対応）
- あいさつメッセージ
- 応答メッセージ
- Webhook

**Phase 1 で Webhook を有効にする際、応答メッセージと二重に返信されないよう注意する。**
どちらで返すかを機能ごとに決めて記録すること。
