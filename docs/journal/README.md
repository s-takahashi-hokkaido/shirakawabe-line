# 作業日誌

セッションごとに「やったこと・決まったこと・次にやること」を残す。
管理画面の操作は履歴が残らないため、**何をいつ変えたか**の一次記録にもなる。

## ファイル

- 1日1ファイル: `YYYY-MM-DD.md`（日付は日本時間）
- 同じ日に複数回作業したら、同じファイルに `## セッション2` として追記する
- Claude Code は起動時に**最新の1ファイル**を自動で読み込む（`.claude/settings.json` の SessionStart フック）
- 書くときは Claude Code で `/journal` と打つ（`.claude/skills/journal/`）

## フォーマット

```markdown
# YYYY-MM-DD

## セッション1

### やったこと
- （管理画面で変えた設定は「どこを・何から何へ」まで書く）

### 決まったこと
- （決定事項は docs/decisions.md にも反映する）

### わかったこと・要確認
- （調べて分かった事実は出典を添える。未確認は `要確認:` を付ける）

### 次にやること
- [ ] 優先度の高い順に並べる

### 待ち・ブロッカー
- （誰の何を待っているか）
```

## 書かないこと

**このリポジトリは GitHub 上で公開（PUBLIC）されている。** 公開範囲を変えるまでは特に厳守する。

- 支援者・有権者の氏名、連絡先、LINEユーザーID、メッセージの中身
- 後援会名簿の内容
- 認証情報（パスワード、アクセストークン、チャネルシークレット）
- 本人ヒアリングで出た機微な話（NG話題、過去の炎上、票読み、支援団体との関係）
  → 公開範囲を非公開にするまでは「ヒアリング実施、T-xx が確定」程度にとどめる

詳細は [../compliance.md](../compliance.md)。
