## 1. 公職選挙法（ネット選挙運動）

2013年の公職選挙法改正により、インターネットを使った選挙運動が解禁された。
ただし**手段によって扱いが違う**ことが設計上の最重要ポイント。

### 手段による区分

| 手段 | 候補者・政党 | 一般有権者 | 備考 |
|---|---|---|---|
| ウェブサイト等（SNS、ブログ、動画、**LINE**） | ○ | ○ | 誰でも可 |
| 電子メール（SMTP方式）・SMS | ○ | **×** | 事前同意等の要件あり |

**LINEのメッセージ機能は「ウェブサイト等を利用する方法」に整理される**（総務省の解釈）。
したがって支援者による拡散も可能。

> 要確認:この整理は総務省のネット選挙運動ガイドに基づく一般的な理解だが、
> 実務では選管への確認を推奨。

### 設計に落とし込むルール

| 制約 | システムでの対応 |
|---|---|
| **投票日当日の選挙運動は禁止** | 配信機能に期間ガードを実装。投票日は配信APIを物理的にブロックする。既存コンテンツの残置は可、更新は不可 |
| **事前運動の禁止**（告示前は政治活動） | 告示前後で文面テンプレートを切り替える。告示前に「投票してください」系の文言を出さない |
| **表示義務**（連絡先の表示） | 選挙運動用の配信文フッターに連絡先を自動付与する |
| **有料ネット広告の禁止** | 広告連携機能を実装しない |
| **18歳未満の選挙運動禁止** | ボランティア募集フォームに年齢確認を必須項目として入れる |
| **買収の禁止** | 友だち紹介インセンティブ、プレゼント企画等は実装しない |
| **なりすまし・虚偽表示の禁止** | アカウントの真正性を明示。認証済アカウント取得を推奨 |

### スケジュール

| | 日程 | 状態 |
|---|---|---|
| 統一地方選（前半戦） | 2027年4月 | **要確認:正式な期日は臨時特例法で決まる**（2026年中に成立の見込み。2026-09-17時点で成立を未確認） |
| 札幌市議会議員の任期満了 | 2027年5月1日 | 確定（[札幌市選管](https://www.city.sapporo.jp/senkan/keihatu/ninki/ninki.html)、2026-09-17確認） |
| **政治活動用ポスターの掲示禁止** | **2026年11月1日ごろ 〜 投票日** | 要確認:正確な開始日は札幌市選管に確認する。→ §1.1 |
| 告示日 | 2027年4月2日(金) 見込み | 要確認。政令市の市議選は選挙運動期間9日間 |
| 投票日 | 2027年4月11日(日) 見込み | 要確認 |

**2026-09-17時点で、告示日まで197日・投票日まで206日（どちらも見込みの日付で計算）。約6ヶ月半しかない。**
選挙運動期間の9日間は刈り取りに過ぎず、
勝負は**告示前の政治活動期間に何人の友だちを貯め、投票日までつながりを保てるか**。

### 1.1 印刷物の規制（QRコードの載せ先に関わる）

LINEそのものの規制ではないが、友だち追加QRを**どの印刷物に載せられるか**が変わる。

| 規制 | 内容 | QR展開への影響 |
|---|---|---|
| **政治活動用ポスターの掲示禁止期間**（公選法143条） | 本人の氏名・氏名が類推される表示・後援団体名が入ったポスターは、**任期満了日の6か月前から選挙期日まで**、選挙区内に掲示できない | ポスターにQRを載せても、**2026年11月1日ごろには剥がすことになる**。QRを載せる印刷物の主力にしない |
| **あいさつ状の禁止**（公選法147条の2） | 候補者となろうとする者・公職にある者は、選挙区内の人に**年賀状・寒中見舞・暑中見舞などのあいさつ状を出せない**（**期間を問わず禁止**）。例外は答礼のための自筆のものだけ。印刷・署名だけ自筆・代筆は例外に当たらない | **年賀状・暑中見舞いにQRを刷る施策はやらない** |

名刺・活動報告のビラなど、掲示しない印刷物の扱いは上記と別。
要確認:告示後（選挙運動期間中）に、政治活動用のビラ等をどこまで配れるか。

出典:[練馬区選管](https://www.city.nerima.tokyo.jp/kusei/senkyo/undou/bunshotoga.html)、[佐世保市選管](https://www.city.sasebo.lg.jp/senkyo/senkyo/aisatujyounokinnsi.html)、[公職選挙法147条の2](https://lawzilla.jp/law/325AC1000000100?n=ln147_2&mode=only)（2026-09-17確認）

## 2. 政治資金規正法（寄付機能を作る場合）

現時点では寄付機能を実装する予定はない。実装する場合は以下の制約がある。

- 外国人からの寄付は禁止
- 匿名寄付は禁止
- 企業・団体からの寄付には制限がある
- 公職の候補者個人への寄付には制限がある（政治団体経由が原則）

**寄付導線を実装する前に必ず専門家に確認する。**

## 3. 個人情報

支援者データは**政治的信条に関わる情報**であり、通常の顧客データより機微度が高い。

### ルール

- **リポジトリに実データを置かない**（名簿、氏名、連絡先、LINEユーザーID）
- フォームで情報を取得する際は**利用目的を明示**する
- プライバシーポリシーを用意し、フォームから参照できるようにする
- **保管期間と選挙後の削除方針**を事前に決める（→ [decisions.md](decisions.md)）
- データの管理責任者を明確にする（候補者本人か、後援会か）

### 秘密情報の管理

| 種類 | 管理方法 |
|---|---|
| チャネルアクセストークン / シークレット | Cloudflare Workers Secrets。ローカルは `.dev.vars`（gitignore済） |
| 管理画面のログイン情報 | **共有しない**。人単位で権限を付与する |

## 4. 報酬・稼働の扱い

開発者の関わり方（無償ボランティア / 業務委託）を**着手前に明確にする**。

- 選挙運動員への報酬には公職選挙法上の制限がある
- 一方、選挙運動用ウェブサイト等の作成を業者に委託する費用は別扱いとする整理がある

> 要確認:この境界は判断が微妙な領域。**専門家の確認が必須**。
> 曖昧なまま作業を進めない。
