# 本人ヒアリングシート

**ヒアリングの目的は機能を聞き出すことではなく、
本人も言語化できていない目的をこちらで言語化すること。**

「公式ライン作って」という依頼は、多くの場合「他の候補が持っているから」が出発点で、
その裏に本当の困りごとがある。そこを掘る。

## 進め方

- 60分、できれば対面。録音の許可を取る
- 冒頭で「今日は技術の話はしません。何のために使うかを決めたいです」と宣言する
- **技術用語（API、Webhook、セグメント）を一切使わない**
- **「どんな機能が欲しいですか」は絶対に聞かない。**
  候補者は機能を知らないので、答えは「おまかせ」か他候補の劣化コピーになる。
  **困っていることだけを聞く**
- 数字は必ずその場で言ってもらう。「たくさん」「けっこう」で流さない

---

## A. 狙いを掘る（最初の15分・最重要）

| # | 実際に言う言葉 | 何を判断するか |
|---|---|---|
| A1 | なぜLINEを作ろうと思ったんですか。きっかけは何でした? | 真の動機。他候補の模倣か実需か |
| A2 | もうLINEを使っている候補で、参考にしたい人はいますか | イメージの具体度 |
| A3 | できたら、まず誰に何を届けたいですか | ターゲットと最初のコンテンツ |
| A4 | 1年後これがどうなっていたら「やってよかった」と思いますか | **成功の定義**。KPIの元 |
| A5 | 逆に、どうなったら失敗だと思いますか | 地雷。A4より本音が出る |
| A6 | (a)支援者とのつながり維持 (b)ボランティア募集 (c)問い合わせ対応 (d)政策発信 (e)投票の呼びかけ — **この中から1位と2位だけ選んでください** | 優先順位 |

**A6は必ず絞らせる。**「全部大事」と言われたら「最初の3ヶ月で1つだけやるなら?」と聞き直す。

## B. 選挙の前提

| # | 質問 | なぜ聞くか |
|---|---|---|
| B1 | 現職か新人か。過去の出馬歴と得票数は | 認知ゼロからか、固定票があるか |
| B2 | 政党の公認・推薦はあるか | 党の素材・名簿・ガイドラインが使えるか。党の規約がシステムを縛る場合がある |
| B3 | 目標得票数と、その根拠は | 友だち数の目標を逆算できる |
| B4 | 票の基盤はどこか（地縁 / 業界団体 / 労組 / 同窓 / 前職の顧客 / 宗教） | LINEで届く層か |
| B5 | 北区内で重点を置く地区は（麻生・新琴似・屯田・篠路・太平・あいの里 等） | 地区別配信をやる意味があるか |
| B6 | 対抗馬は何人で、うちLINEをやっているのは | 競合状況 |

## C. 既存の接点資産（最重要）

> **前提:既存の後援会名簿をLINE公式アカウントに一括登録することは技術的にできない。**
> 友だちは本人がQRを読むかURLをタップして追加するしかない。
> 「名簿 → LINE」の移行は紙とリアル接点の仕事であり、ここが最大のボトルネック。

| # | 質問 | なぜ聞くか |
|---|---|---|
| C1 | 後援会名簿は何件ありますか。連絡手段は住所? 電話? メール? | 移行の母数と手段 |
| C2 | ご自身の**個人LINE**で有権者と何人つながっていますか | **最速の初期友だち源**。初日の施策になる |
| C3 | 活動報告のビラ・会報などの定期的な印刷物はありますか。次はいつ? | QRを刷り込む機会。**年賀状・暑中見舞いは公選法のあいさつ状禁止に当たるため対象外** → [compliance.md §1.1](compliance.md) |
| C4 | **名刺・チラシの次の印刷はいつですか** | **QRコードの実質的な締切。告示まで約6ヶ月半しかなく、1回逃すと取り返せない** |
| C5 | 年間の対面接点（集会・朝立ち・祭り・会合）は何回、何人規模? | 友だち獲得の主戦場 |
| C6 | X・Instagram・Facebook・YouTube のフォロワー数、WebサイトのPVは | 既存デジタル導線の実力 |
| C7 | 政治活動用ポスターは貼っていますか。何枚・どこに? | **2026年11月1日ごろから掲示禁止**（要確認）。ポスターにQRを載せる意味は薄い → [compliance.md §1.1](compliance.md) |

## D. 運用体制（最大の失敗要因）

| # | 質問 |
|---|---|
| D1 | **届いたメッセージに返信するのは誰ですか。本人ですか、スタッフですか** |
| D2 | 返信にかけられるのは1日何分ですか |
| D3 | どれくらいの速さで返したいですか（即日 / 翌日 / 数日） |
| D4 | ご自身のスマホで操作する気はありますか。スマホ操作は得意ですか |
| D5 | 配信する文章は誰が書きますか。最終チェックは誰が? |
| D6 | 常駐スタッフ・ボランティアは何人いますか |
| D7 | 開発担当はどこまでやりますか。運用もですか、仕組みを渡して終わりですか |

**D7は聞きにくいが、エンジニア1人体制では最重要。投票日まで約7ヶ月、放っておくと稼働を際限なく吸われる。**

## E. コンテンツ

| # | 質問 |

| E1 | 政策は文章になっていますか。何本ありますか |
| E2 | プロフィール・経歴・写真素材はどこにありますか。使用許可は? |
| E3 | 活動予定はどこで管理していますか（Googleカレンダー / 紙 / 頭の中） |

**E4はその場で埋まらなければ宿題にして必ず回収する。** → [auto-reply.md](auto-reply.md)

## F. トーン・NG

| # | 質問 |
|---|---|
| F1 | 一人称と文体の希望（「私」「僕」/ 硬め・柔らかめ） |
| F2 | **絶対に触れてほしくない話題、過去に炎上したことは** |
| F3 | 顔写真の使い方、ご家族の露出は可か |
| F4 | 支援団体・支持政党との関係で配慮が必要な相手は |

## G. コンプラ・責任の所在

| # | 質問 | なぜ聞くか |
|---|---|---|
| G1 | 選挙に詳しい相談相手は誰ですか（選挙プランナー / 先輩議員 / 選管 / 弁護士） | **公選法の判断を開発担当が背負わないため** |
| G2 | 迷ったとき誰に聞けばいいですか | エスカレーション先の確定 |
| G3 | 集めた支援者データの管理責任者は誰ですか | 個人情報の責任主体 |
| G4 | 選挙後、集めたデータはどうしますか | 保管・削除方針 |

**G1・G2は必ず名前を出してもらう。**「たぶん大丈夫」で進めると責任が開発側に来る。

## H. お金と所有

| # | 質問 |
|---|---|
| H1 | LINEの月額はいくらまで出せますか（0円 / 5,000円 / 15,000円 / それ以上） |
| H2 | 支払いは誰の名義・どの方法ですか |
| H3 | アカウントの名義は本人ですか、後援会ですか |
| H4 | **開発担当の関わりは無償ボランティアですか、業務委託ですか** |
| H5 | 選挙後もアカウントを続けますか |

**H4は言いにくくても初回に出す。** 公選法の報酬規制に関わる論点でもあるため、
G1の相談先に確認してもらう前提で、関係の性質だけは先に決める。

## その場で決め切る（宿題にしない）

1. アカウントの名義と支払い方法（H2・H3）
2. 返信担当者（D1）
3. 優先順位の1位（A6）
4. 次の印刷物の締切（C4）
5. 公選法の相談先の名前（G1）

**この5つが埋まらないなら、コードは1行も書かない。**

## その場で決めなくていい

機能の詳細、デザイン、配信文面、システム構成。
**これらを議題にすると会議が発散して、上の5つが決まらないまま終わる。**
