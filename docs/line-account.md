# LINE公式アカウントの構造・権限・開設手順

## 1. 3つのコンソール

権限が別管理になっているのが最初にハマるポイント。

```
LINE Business ID（ログインアカウント。人ごとに1つ）
 ├─ LINE Official Account Manager（manager.line.biz）  ← 運用側
 │    リッチメニュー / 配信 / 1:1チャット / 分析 / 友だち管理
 └─ LINE Developers Console（developers.line.biz）     ← 開発側
      プロバイダー > Messaging APIチャネル
      （アクセストークン、Webhook URL、LIFF）
```

公式アカウントを作成後、Manager の「設定 > Messaging API」から有効化すると
Developers 側のチャネルと紐づく。**Phase 1 に入るまでこの操作は不要。**

### スマホアプリ

「LINE公式アカウント」アプリ（iOS/Android）がある。
1:1チャットの返信、簡易配信、LINE VOOM投稿ができる。
**候補者本人の運用の実体はこのアプリになる。**

ただし機能に差がある。確認済みの差分:

| | スマホアプリ | Web管理画面(PC) |
|---|---|---|
| リッチメニューの画像 | 1枚まるごとアップロードのみ | 要確認:枠ごとに画像・テキストを配置できる簡易エディタがあるはず |
| 1:1チャット返信 | ○（こちらが本命） | ○ |

## 2. 権限

**1つの公式アカウントに複数人を権限付きで招待できる。**
候補者本人のIDを借りる必要も、パスワードを共有する必要もない。

```
公式アカウント「白川部慶太」
 ├─ 白川部慶太（管理者）  ← 作成者。名義・支払いはここ
 ├─ 開発担当（管理者）    ← 自分のログインで全操作
 └─ スタッフ（運用担当者）← 必要なら返信のみ担当
```

### 権限の種類（Official Account Manager）

| 権限 | できること |
|---|---|
| 管理者 | 全操作 + 権限の付与・剥奪 |
| 運用担当者 | 権限管理と一部設定以外ほぼ全部 |
| 運用担当者（配信権限なし） | 配信できない |
| 運用担当者（分析権限なし） | 分析を見られない |

LINE Developers Console 側は Admin / Member / Tester の別体系。

### 招待手順

1. 管理画面 > **設定 > 権限管理 > メンバーを追加**
2. 招待URLを発行
3. 招待された側が自分の LINE Business ID でログインして参加

誰が何をしたかのログが残るため、パスワード共有より安全。

## 3. 個人アカウントとの関係

- 公式アカウントは個人アカウントとは**完全に別人格**。
  友だち側に管理者の個人プロフィールや個人LINE IDが見えることはない。
- Business ID の登録は「LINEアカウントで登録」「メールアドレスで登録」の2通り。
  メールアドレス登録なら個人LINEと紐づけずに作成できる。
- ただし実務上は、本人が個人LINEで登録しておくと
  スマホアプリでの通知受け取りと返信が楽になる。**露出しないので実害はない。**

## 4. 名義とアカウントの所有

**名義は候補者本人または後援会にする。開発者名義で作らない。**

- 認証済アカウントの審査に出す事業者情報、支払い情報は名義と紐づく
- 選挙後の引き継ぎで問題になる

> 要確認:アカウントそのものの「譲渡」機能は基本的にないと認識している。
> 管理者を追加して元の管理者を外せば実質的な引き継ぎは可能だが、
> 支払い情報は別途対応が必要。

### アカウント名

**最初に確定させること。** 後から変更しづらい（変更後一定期間は再変更不可）。
**認証済アカウントの名称変更は原則受け付けられない**（社名・サービス名の変更に伴う場合のみ再審査）
— [LINE公式アカウントガイドライン](https://terms2.line.me/official_account_guideline_jp)。
**認証済の申請は、アカウント名を確定させてから出す。**

検索されやすさを考えると「白川部けいた」のようにひらがなを混ぜる表記が有利。

## 5. 認証済アカウント

| | 未認証（グレーバッジ） | 認証済（青バッジ） |
|---|---|---|
| LINEアプリ内検索に表示 | × | ○ |
| 請求書払い | × | ○ |
| 販促物の利用 | 制限あり | ○ |
| 属性セグメント配信 | × | ○（+友だち数が一定以上必要） |

**認知が課題なら認証済は取るべき。** 審査に時間がかかるため早めに申請する。
申請には事業者情報が必要になるので、本人側から情報を取得する。

> 要確認:属性セグメント配信に必要な友だち数の閾値。

LINE公式アカウントガイドラインには、政治家・政治団体を認証済の対象外とする記述は見当たらない（2026-09-17確認）。
ただし審査に通るかは申請するまで分からない。

## 6. 開設手順（本人に依頼する内容）

```
1. https://www.linebiz.com/jp/entry/ にアクセス
2. 「LINEアカウントで登録」を選択
   ※個人LINEが有権者に見えることはない
3. アカウント情報を入力
   ・アカウント名：「白川部けいた」など、検索されやすい表記で（後から変更しづらい）
   ・業種：政治・行政 系
4. 作成完了

5. 管理画面（https://manager.line.biz/）を開き
   「設定」→「権限管理」→「メンバーを追加」
   → 発行されたURLを開発担当に送付
```

支払い情報は当面不要（無料プランで開始）。

---

## 7. 権限取得後にやること

1. **応答設定の確認** — Webhook と 応答メッセージ の二重返信を避ける設定
2. **あいさつメッセージ**の作成 → [auto-reply.md](auto-reply.md)
3. **リッチメニュー**の初版 → [rich-menu.md](rich-menu.md)
4. **認証済アカウントの申請**
5. **友だち追加QR / URL** の発行と、印刷物への展開
