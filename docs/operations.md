# 運用体制

## 1. 役割分担

| 担当 | 使うもの | やること |
|---|---|---|
| **開発担当** | Web管理画面（PC） | リッチメニュー設計、自動応答の設定、配信テンプレ作成、分析、コード |
| **白川部慶太** | スマホアプリ「LINE公式アカウント」 | **1:1チャットの返信**、日々の投稿 |

本人には**スマホで返信するところだけ**やってもらう。仕組み側は開発担当が触る。

## 2. 最大の失敗要因:返信されないこと

公式アカウントが死ぬ原因の大半は「返信されない」「更新が止まる」。
**更新が止まったアカウントは、無いよりマイナス。**

LINEは他のSNSと違い、有権者から直接メッセージが届く。
返信されないと「見てもらえなかった」という個人的な失望が残る。

### 公開前に必ず決めること

- [ ] 届いたメッセージに誰が返信するか
- [ ] 返信にかけられる時間（1日何分）
- [ ] 返信の目標速度（即日 / 翌日 / 数日）
- [ ] 本人がスマホで操作する意思と習熟度

**これが決まるまでアカウントを公開しない。**

## 3. 配信のルール

- **push は「今知らせないと意味がないもの」だけ** → [cost.md](cost.md)
- 配信文は**必ず誰かがレビューしてから送る**。本人の発言として世に出る
- 選挙運動期間中の配信文には**連絡先を表示する**（公選法の表示義務）
- **投票日当日は配信しない**（公選法）
- 配信したら [broadcast/](broadcast/) に記録を残す

- **候補者本人の発言として出力される**ことを常に意識する

## 5. ドキュメントの更新

管理画面の設定はバージョン管理されない。
**設定を変更したら、対応するdocsを更新する。**

これにより変更履歴が残り、選挙後の引き継ぎもできる。
