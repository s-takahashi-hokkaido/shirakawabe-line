# 決定事項と未確定事項

## 決定事項

| # | 決定 | 理由 | 決定日 |
|---|---|---|---|
| D-01 | **reply中心、pushは時々** | pushのみ通数課金。replyは無料 → [cost.md](cost.md) | 2026-09 |
| D-02 | **Phase 0 はコードを書かない** | 管理画面の標準機能で足りる。コードから入ると友だちゼロのBotができる | 2026-09 |
| D-03 | 技術スタックは TypeScript / Hono on Cloudflare Workers / D1 | 常時起動不要・無料枠・Webhook応答速度 | 2026-09 |
| D-04 | Phase 1 の初期スコープは ①流入経路トラッキング ②Webhook基盤 ③問い合わせ転送 | 認知が課題であり、経路の可視化が意思決定を変える | 2026-09 |
| D-05 | アカウント名義は候補者本人または後援会。**開発者名義にしない** | 審査・支払い情報が名義に紐づく。選挙後の引き継ぎ | 2026-09 |
| D-06 | 権限は人単位で付与する。パスワードを共有しない | 監査ログが残る。安全性 | 2026-09 |
| D-07 | 認証済アカウントを申請する | LINEアプリ内検索に表示される。認知が課題のため。審査に時間がかかるので早期申請 | 2026-09 |
| D-08 | 支援者の実データ・認証情報をリポジトリに置かない | 個人情報の機微度 → [compliance.md](compliance.md) | 2026-09 |
| D-09 | 有料広告連携・紹介インセンティブは実装しない | 公選法（有料ネット広告の禁止、買収規制） | 2026-09 |
| D-10 | 管理画面の設定内容をdocsに記録する | 設定はバージョン管理されない。引き継ぎ性の確保 | 2026-09 |
