# shirakawabe-line

白川部慶太 公式LINEアカウントの構築・運用リポジトリ。

2027年統一地方選・**札幌市議会議員選挙（北区選挙区）**に向けて、公式LINEアカウントを
「支援者を貯めて温め続ける装置」として構築・運用する。コードだけでなく、
管理画面の設定内容・運用手順・配信実績もここで一元管理する。

---

## 基本方針

### 1. reply中心、pushは時々

LINE公式アカウントは**配信（push）のみが通数課金**される。
応答メッセージ・あいさつメッセージ・リッチメニュー経由の応答・1:1チャットの返信は**無料**。

- push は「今知らせないと意味がないもの」だけ（街頭演説の告知、緊急のお知らせ、投票依頼）
- それ以外はリッチメニューと自動応答に置き、**取りに来てもらう**
- 実装時は「これは push である必要があるか」を必ず自問する

詳細は [docs/cost.md](docs/cost.md)。

### 2. Phase 0 はコードを1行も書かない

管理画面（LINE Official Account Manager）だけでできることが想像以上に多い。
まず標準機能だけで公開して運用を回し、**実地で足りないと分かった部分から**コードを書く。

コードから入ると、ほぼ確実に「友だちが誰もいないBot」ができあがる。

### 3. 認知拡大の主戦場はLINEの外

LINE公式アカウントは新規認知を取るツールではない。友だち追加は相手の能動的な行為であり、
かつ選挙では**有料ネット広告が禁止**されているため、広告で友だちを増やす手も使えない。

LINEの役割は「**一度接点を持った人を、選挙まで離さない**」こと。
したがって全オフライン接点（名刺・チラシ・街頭・会合）にQRを置き、
**どの経路から来たかを測る**ことが最重要機能になる。

## 技術スタック（Phase 1 以降）

- TypeScript
- Hono on Cloudflare Workers
- D1（SQLite）
- LIFF（Phase 2）

常時起動が不要で無料枠に収まり、Webhookの応答速度要件を満たしやすいため。
インフラコストはほぼゼロで、**コストの実体はLINEのプラン代**。

---

## ディレクトリ構成

```
docs/           運用ドキュメント・設定の記録・原稿
assets/         リッチメニュー画像などの素材（Phase 0から）
src/            アプリケーションコード（Phase 1から）
```

管理画面上の設定はバージョン管理されないため、
**設定内容をdocsに記録しておく**ことで変更履歴と引き継ぎ性を確保する。
